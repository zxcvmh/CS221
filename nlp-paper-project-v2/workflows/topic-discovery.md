# Workflow: Topic Discovery

Goal: find an ACL-valid paper for a reproducible VQA application project with an NLP-centered contribution.

Sequence:
`DEFINE APPLICATION → DEFINE VQA FAILURE → SEARCH ACL → VERIFY PAPER → AUDIT ARTIFACTS → COMPARE CANDIDATES → REVIEW G1 → SELECT/REJECT`

1. Define VQA task, target language(s), use case, datasets, compute, and unacceptable risks.
2. Define a language-centric bottleneck. Do not start from a fashionable model.
3. Search ACL Anthology and official venue pages first.
4. For each candidate record title, authors, venue/year, Anthology ID, ACL URL, task, language component, VQA relevance, official repo, code/checkpoint status.
5. Pre-screen reproducibility:
   - GREEN: artifacts appear sufficient;
   - YELLOW: important artifact uncertain;
   - RED: critical artifact unavailable.
6. Compare candidates using factual evidence: NLP relevance, VQA relevance, reproducibility, compute feasibility, evaluation quality, identifiable gap.
7. Send candidate evidence to reviewer for G1.
